# Nabu Code

A standalone coding editor designed to work with coding agents through their official command-line tools.

Product name: **Nabu Code**. Short name: **Nabu**. Company: **Dpro**.

## Product direction

Open a project, edit its files, and collaborate with Claude Code or Codex from an integrated interface. The intended connection uses the tools' supported local interfaces and their own authentication and permission flows. Exact integration capabilities and subscription terms require verification before implementation.

Nabu Code is a separate product from Dpro Bot and must work independently. Optional integration with Dpro Bot can be added later.
